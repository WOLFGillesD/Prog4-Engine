# Prog4-Engine

Project for programming 4 course of DAE Game Development.


[![Build Status](https://github.com/WOLFGillesD/Prog4-Engine/actions/workflows/cmake.yml/badge.svg)](https://github.com/WOLFGillesD/Prog4-Engine)

# Controls
## Controller
* D-Pad to move.
* X to inflict damage.
* A and B to pickup pallets.

## Keyboard
* WASD to move.
* C to inflict damage (lose a life).
* X and Z to pick up pallets.

# Sound
* Background music starts playing on startup.
* When player loses life sound plays.
